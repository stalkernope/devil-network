# DEVIL NETWORK bot v4

Полностью бесплатный автопостинг в Telegram через GitHub Actions.

## Запуск (10 минут)
1. @BotFather → /newbot → скопируй токен. Добавь бота админом в канал (право публикации).
2. Создай **публичный** репозиторий на GitHub и залей туда всё из архива (включая папку `.github`).
3. Settings → Secrets and variables → Actions → New repository secret:
   - `BOT_TOKEN` — токен бота
   - `CHANNEL_ID` — `@username_канала`
4. Actions → autopost → Run workflow. Появится первый пост.
5. Проверка рубрик: Run workflow → в поле rubric впиши `quiz` (или tip, term, tool, top_day, top_week, thefts).

## Необязательные секреты
| Секрет | Зачем |
|---|---|
| `SUGGEST_URL` | кнопка «💡 Предложить тему» под постами (ссылка на тебя или чат) |
| `EXTRA_CHANNELS` | зеркала в другие каналы: `@ch2,@ch3` (бот — админ и там) |
| `ADMIN_CHAT_ID` | твой числовой id (узнать у @userinfobot): бот напишет, если пост не вышел |
| `VK_TOKEN`, `VK_GROUP_ID` | кросспост во ВКонтакте на стену сообщества |
| `LLM_API_KEY`, `LLM_URL`, `LLM_MODEL` | свой ИИ вместо GitHub Models (любой OpenAI-совместимый, например Groq или Gemini) |

## Что умеет
- ~35 постов в сутки: новости, даркнет, взломы, крипто-кражи, мошенничество, обновления Telegram, весь IT
- Важное идёт первым (оценка по ключевым словам и свежести), срочное помечается 🔥 СРОЧНО
- Дубли одной новости из разных источников отсекаются
- Статьи по YouTube-видео и пересказы Telegram-каналов (ИИ)
- Рубрики по МСК: 09:00 совет дня, 12:00 квиз, 15:00 словарь хакера, 19:00 ср инструмент недели, 18:00 пт кражи недели, 21:00 топ-5 дня, вс 19:00 итоги недели
- Под каждым постом кнопка «Поделиться»; ночью (23:00–08:00 МСК) посты уходят без звука
- Счётчик подписчиков в дайджестах («Нас уже 20 000»)

## Настройка
- `config.py` — источники, Telegram-каналы, YouTube, расписание рубрик, порядок типов постов
- `content.py` — база советов, терминов, инструментов и квизов: дописывай свои строки
- `INTERVAL_MIN` в `post.yml` — интервал между постами (минуты)

## Если что-то не работает
Actions → последний запуск → лог. Строки `skip …` — источник не ответил, это нормально.
Расшифровки YouTube иногда блокируются для серверов GitHub — тогда видео уходит без статьи.
